# 📝 Projeto To_Do: Praticando Lógica de Programação

Este repositório foi criado com o objetivo puramente técnico de exercitar minha lógica de programação utilizando **JavaScript Vanilla**. O foco aqui é o "como as coisas funcionam por baixo do capô", desde a criação dinâmica de elementos até a gestão de fluxos de dados.

---

## 🚀 Evolução do Projeto (Roadmap de Commits)

O projeto foi planejado em etapas para que eu pudesse focar em um desafio de cada vez:

- [x] **1º Commit (Lógica Core):** Foco total no funcionamento. Implementação da criação de categorias, inserção de tarefas e contagem de itens concluídos.
- [x] **2º Commit (Interface e Layout):** (Status Atual) Refinamento visual utilizando CSS Grid e Flexbox, tornando a experiência do usuário mais agradável e organizada.
- [ ] **3º Commit (Persistência):** Prática com armazenamento de dados. O objetivo será implementar uma forma de manter os cards salvos (seja via LocalStorage ou integração com Banco de Dados).

---

## ✨ O que este projeto exercita?

- **DOM dinâmico:** Criação e remoção de elementos HTML em tempo real.
- **IDs Únicos:** Lógica para garantir que uma tarefa seja adicionada exatamente na categoria correta, sem conflitos.
- **Contadores Globais:** Gestão de estados simples para exibir a produtividade do usuário.
- **Estruturação Grid:** Organização de cards que se adaptam ao conteúdo.

---

## 🛠️ Tecnologias

*   **HTML5** (Estrutura)
*   **CSS3** (Layout e Estilização)
*   **JavaScript ES6+** (Lógica de execução)
